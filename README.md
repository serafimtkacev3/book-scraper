
# Book Scraper

Учебный Python-проект для сбора и анализа информации о книгах с сайта Books to Scrape.

## Возможности

- Парсинг HTML с помощью requests и BeautifulSoup
- Асинхронный сбор данных через aiohttp и asyncio
- Обработка ошибок через try/except/finally
- Использование dataclass, Counter и defaultdict
- Сохранение результатов в JSON
- Логирование работы программы
- Измерение времени выполнения
- Построение графиков через matplotlib
- Запуск в Docker

## Установка

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить проект:

```powershell
python -m pip install -e .
```

## Запуск парсера

```powershell
python -m book_scraper.async_scraper
```

Парсер собирает книги с трёх страниц сайта и сохраняет результат в async_books.json.

## Построение графиков

```powershell
python -m book_scraper.charts
```

## Запуск через Docker

Собрать образ:

```powershell
docker build -t book-scraper .
```

Запустить контейнер:

```powershell
docker run --rm -v "${PWD}:/data" -w /data book-scraper
```

## Результаты

При успешном выполнении программа собирает 60 книг, рассчитывает среднюю, минимальную и максимальную цену и сохраняет данные в JSON.

## Анализ данных через Pandas

Проект использует Pandas для анализа собранных книг.

Возможности:
- Расчёт средней, минимальной и максимальной цены
- Фильтрация и сортировка книг
- Поиск пропущенных значений
- Статистический анализ данных

Запуск:

`python -m book_scraper.analysis`

## Поиск изменений

Парсер сравнивает новые данные с предыдущими.

Для обнаружения изменений используется SHA-256.

Программа определяет:
- Новые книги
- Книги с изменёнными данными

Результаты сохраняются в `async_books.json`.

История запусков сохраняется в `runs.json`.

## Автоматический запуск

Планировщик автоматически запускает парсер через заданный интервал.

Запуск:

`python -m book_scraper.scheduler`

Интервал настраивается в файле `scheduler.py`.
По умолчанию — 600 секунд (10 минут).

Остановка: Ctrl+C.

## Автоматические тесты

Для проверки логики используются тесты pytest.

Установка:

`python -m pip install pytest`

Запуск:

`python -m pytest -v`

Тесты проверяют правильность определения ценовых категорий.
